# MaintKit

## Team Member

Thomas Gross

## Project Abstract

MaintKit is an industrial maintenance preparation application designed to help maintenance technicians identify the tools required for specific equipment maintenance tasks. Users can search for equipment by name or identification number, select a maintenance procedure, and generate a checklist containing the required and recommended tools needed to perform the job. The system is intended to reduce forgotten tools, unnecessary travel, maintenance delays, and equipment downtime by helping technicians prepare before beginning a maintenance task.
